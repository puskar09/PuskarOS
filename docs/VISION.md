# Puskar OS

## Vision

Puskar OS is an AI-powered personal operating system built for ambitious builders, students, and future AI engineers.

It is designed to remove decision fatigue by bringing learning, projects, career growth, AI knowledge, fitness, and daily execution into one focused workspace.

Instead of switching between multiple applications like Notion, Spotify, GitHub, Google Calendar, ChatGPT, Kaggle, and dozens of browser tabs, Puskar OS becomes the single place where a user plans, learns, builds, and grows every day.

---

# Why Puskar OS Exists

Modern learning is fragmented.

Students spend more time deciding **what to do next** than actually doing meaningful work.

Puskar OS exists to solve this problem.

Every morning, the operating system should answer one simple question:

> **What should I do today to become a better AI Builder?**

The goal is to remove distractions, reduce decision fatigue, and create a system where learning naturally becomes building, and building naturally becomes progress.

---

# Mission

Help builders consistently learn, build, ship, and grow through one intelligent operating system.

# Core Philosophy

Every day should have only one mission.

Instead of overwhelming the user with hundreds of tasks, Puskar OS guides them through a structured daily journey.

Learn.

Build.

Ship.

Reflect.

Repeat.

---

# Core Principles

* Clarity over complexity.
* One mission every day.
* Learn first, build immediately after.
* AI should assist, not replace thinking.
* Every feature must reduce distractions or increase meaningful progress.
* Beautiful, minimal and calm user experience.

---

# Long-Term Vision

Puskar OS will evolve into an AI-powered operating system that understands its user.

It will:

* Create personalized learning plans.
* Track projects and career growth.
* Recommend AI concepts to learn.
* Monitor GitHub progress.
* Track fitness and health.
* Summarize important AI news.
* Suggest what to build next.
* Help users become world-class AI engineers through consistent execution.

---

# Success Metric

If someone opens Puskar OS every morning without thinking about what to do next, then the product has achieved its purpose.

The operating system should become the user's daily starting point for learning, building, and growing.
